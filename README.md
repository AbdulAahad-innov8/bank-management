# Bank Management System

A console-based Bank Management System developed using Python to simulate basic banking operations. This project demonstrates object-oriented programming, file handling, data persistence, and input validation.

## Overview

The Bank Management System allows users to create bank accounts and perform essential banking operations through a menu-driven interface. It was developed to apply Python programming fundamentals to a practical banking use case.

## Features

- **Create Account:** Create a new bank account with customer details.
- **Account Validation:** Validate customer age and PIN during account creation.
- **Deposit Money:** Deposit money into an existing account.
- **Withdraw Money:** Withdraw money from an account.
- **Update Account Details:** Modify existing customer information.
- **JSON Data Storage:** Store and retrieve account records using `data.json`.
- **Object-Oriented Design:** Organize banking operations using Python classes and methods.

## Technologies Used

- Object-Oriented Programming (OOP)

## Getting Started

### Prerequisites

- Python 3 installed on your system
- Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AbdulAahad-innov8/bank-management.git
```

**2. Navigate to the project directory**

```bash
cd bank-management
```

**3. Run the program**

Replace `main.py` with your actual entry-point filename if necessary.

```bash
python main.py
```

## How It Works

1. Run the program in the terminal.
2. Select an operation from the available menu.
3. Enter the required account details.
4. Perform banking operations such as depositing or withdrawing money.
5. Account records are stored and retrieved using JSON file handling.
